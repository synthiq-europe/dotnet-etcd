# Lightweight ADR directory

This directory contains various lightweight ADR files. \
These files describe the decisions made during the design and development
process.

More information on the lADR format can be found in
[Michael Nygard's blog post](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)
on documenting architecture decisions.

- [lADR-001: Language and runtime](001.md)
- [lADR-002: Base client design](002.md)
