# lADR-001: Language and runtime

**Status:** Accepted \
**Date:** 2025-09-15

This entry is based on work described in [DN-001](../design-notes/001.md).

## Context

We require a stable, well-supported language for building a modern .NET etcd
library. \
The choice must provide long-term support, an extensive ecosystem, and
alignment with existing tooling.

Furthermore, we want early access to runtime improvements, and to surface support
issues early in the maintenance process.

## Decision

- Adopt C# as the primary language.
- Adopt .NET LTS as the primary runtime and .NET STS as a
  secondary runtime.
- Track the upcoming .NET LTS Release Candidates as an **optional** tertiary
  runtime, for early validation.

## Consequences

- Establishes a support policy, with .NET LTS as the compatibility baseline.
- Introduces a CI matrix for .NET LTS/STS and a separate, non-blocking lane for
  .NET LTS RC validation.
