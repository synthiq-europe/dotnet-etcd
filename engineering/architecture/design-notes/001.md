# DN-001: Project scope

This document describes the rationale leading to
[lADR-001](../decision-record/001.md).

## Context

Prior to this design note, the objectives were insufficiently defined.
This led to spurious choices in the library's architecture.

The decision was made to throw everything out the window, and to start from
scratch, this time with more explicit choices backed by reasoning supporting the
work.

## Goals & Non-goals

### Goals

- Releasing a library containing an idiomatic .NET etcd client.
- If possible, exposing a programming model, formalizing what consumers of the
  library might attempt informally.
- Integration with significant existing ecosystems, like OpenTelemetry and the
  Microsoft extension libraries.

### Non-goals

- Implementation of server features. This is a client library.
- Legacy API support. Legacy means unsupported by the etcd team.
- .NET Framework support. It might be accepted at a later time, but it is not a
  priority at the moment of writing.
- Niche features, especially features one could reasonably expect the library
  consumer to implement.
